# V102.12 academy timetable plan

Status: later implementation direction. V102.10 does not build academy timetable aggregation.

V102.12 will combine current published course timetables and published global-subject sessions. Protected detail must be redacted by the backend rather than hidden with CSS.

## Course visibility

| Viewer | Display |
| --- | --- |
| Student in matching group | Subject/module details for that group and `ALL` |
| Student viewing another group's session | Course name only |
| Course Teacher | Complete subject/module timetable for that authorised course |
| Teacher's own session | Highlighted with authorised Zoom action |
| Another Teacher's session | Detailed but muted; no Zoom access |
| Course ADMIN or SENIOR | Full details for authorised courses |
| GLOBAL_ADMIN | Full details across the academy |
| Authenticated account without membership | Course name, date and time only |

A label-only course occurrence must not reveal subject, module, group, teacher, Zoom, resources, attendance/planner details, or operational identifiers.

## Global-subject visibility

- FREE sessions show detail to active authenticated central accounts.
- SUBSCRIPTION sessions show detail to subscribers and authorised staff.
- Non-subscribers see the global-subject label only.

The later academy endpoint should return explicit values such as:

```text
visibilityLevel: DETAIL | LABEL
relevant: true | false
canOpenZoom: true | false
```

V102.11 is responsible for exact-dated global timetable sessions and immutable publication before this aggregation layer is built.
