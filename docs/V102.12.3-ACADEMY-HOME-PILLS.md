# V102.12.3 — Academy Home pill timetable

## Purpose

Academy Home is a personalised delivery view, not the full operational timetable.

Program Timetables and the Global Course Scheduler remain the authoritative builders. Academy Home consumes their published/live delivery data and presents only what is useful to the signed-in account.

## Two-day layout

Default columns:

- `TODAY`
- the full weekday name for tomorrow, e.g. `Tuesday`

The navigation arrows move this two-day window one day at a time. The `Today` control restores the current Academy date.

Each day is made of time rows:

`05h45  [ session pill ] [ simultaneous session pill ]`

The time pill shows the start time in the M4L 24-hour format `13h00`.

## Direct relevance

### Student

Detailed Home pills are returned for sessions matching the Student's authorised group and `ALL` rules. ClassGroup `0` retains its established all-groups read policy.

### Program Teacher / Admin / Senior

A Program staff member's directly assigned teaching session is a detailed Home pill.

Other sessions in that same authorised Program are not rendered individually on Home. They are grouped into a muted Program roll-up pill at the applicable time.

The roll-up is expandable because the staff member is already authorised to view that Program's timetable detail.

### GLOBAL_ADMIN

Program activity is rolled up by default and can be expanded for detail. GLOBAL_ADMIN status alone does not mark every Program session as personally relevant.

### No Program membership

The Program remains label-only. It may be rolled up visually, but it is not expandable and the response contains no protected detail.

## Roll-up rule

At each date/start-time:

- render directly relevant sessions individually;
- group all remaining sessions from the same Program into one Program pill;
- if a relevant session from that Program is already visible, the roll-up represents the remaining activity;
- authorised staff may expand the roll-up to see read-only subject/module/group/teacher detail;
- label-only users cannot expand it.

## Global Courses

Global Course DETAIL/LABEL continues to follow FREE/PAID Global Access and assigned-teacher rules. They use the same session-pill visual language but are not folded into Program roll-ups.

## Zoom

A Zoom URL is returned only when all conditions are true:

1. the session is directly relevant to the account;
2. the session status is `SCHEDULED`;
3. the Academy current date equals the session date;
4. the current time in `PlatformTimezone` is at or after the start and before the end; and
5. a Zoom link exists.

The current authorised pill itself is the Zoom action.

Program roll-up detail never grants Zoom to a session merely because the account may inspect its timetable detail.

## Backend redaction

This refinement does not weaken the V102.12 backend redaction contract.

`LABEL` events remain limited to safe label/date/time presentation. Subject, module, group, teacher, Zoom and operational details are not sent to unauthorised accounts.
