# V103.1.0.2 — Academy Home busy-day scrolling

## Problem

A busy day can contain more timetable rows than comfortably fit inside one Academy Home day card. The reported Thursday example contains early Reboot/Hifz activity plus later Global activity, and the `09h30` row must not disappear when a `20h00` row is also present.

## UI change

`renderAcademyTimetable()` now creates an `.academy-day-session-list` inside each `.academy-day`.

The day card itself owns the fixed card dimensions and hides overflow. The session-list child owns `overflow-y:auto`, touch momentum scrolling and stable scrollbar gutter space. The day heading therefore remains stable while the body scrolls independently.

## Ordering safeguard

Both the browser and Worker convert recognizable `HH:MM` or `HHhMM` values to minutes-since-midnight before comparing times. Raw strings are retained only as a fallback/tie-breaker.

This prevents inconsistent zero-padding from producing a sequence such as `20:00` before `9:30`.

## Boundaries

- No timetable source or publication model changes.
- No Access/Central Identity changes.
- No Sheet migration.
- The pending V103.1 Identity Links migration remains optional for this patch.
