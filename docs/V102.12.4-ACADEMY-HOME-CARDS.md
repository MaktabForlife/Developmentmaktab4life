# V102.12.4 — Academy Home swipeable cards

## Presentation
- Academy Home remains personalised and backend-redacted.
- Mobile: one day card visible at a time.
- Larger screens: two day cards side by side.
- Horizontal native scrolling/swiping is enabled with scroll snapping.
- Each day card has independent vertical scrolling.
- Header format: `‹ TODAY - 29-Aug-26 ›` or `‹ Sunday - 30-Aug-26 ›`.
- Session and Program roll-up pills are about 40% narrower than V102.12.3.
- Staff Program roll-ups show only the Program label; session counts are removed.

## Security unchanged
DETAIL/LABEL redaction and current-session Zoom eligibility remain enforced by the Worker.

## Loader carry-forward
Root `/app.js` is part of the release overlay and all legacy portal loader URLs use the V102.12.4 cache key.
