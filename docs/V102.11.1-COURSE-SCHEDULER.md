# V102.11.1 — Course Scheduler and revision workflow

V102.11.1 is a UI/workflow correction over V102.11. Internal `CourseID`, `RunID`, API names and existing Sheet structures are retained for compatibility.

## User-facing terminology

- Reboot Your Maktab and Aalimiyyah are **Programs**.
- Their existing timetable builder is labelled **Program Timetables**.
- A permanent central curriculum item remains a **Global Subject**.
- A scheduled offering of a Global Subject is presented as a **Global Course**.
- Global scheduling is managed in **Course Scheduler**.
- The internal `GlobalSubjectRuns` / `RunID` terminology remains unchanged in storage and APIs.

## Course Scheduler

The previous separate Delivery and Schedule tabs are combined into one workflow.

The screen contains:

1. Editable subject summary table: `Subject | Access | Modules | Status`.
2. Global Course summary table: `Course | Scheduled dates | Sessions | Status`.
3. `Set up / modify a course`: course name, start/end dates, active state and weekly schedule rows.
4. Weekly schedule rows: Day, Start, End, Module, Teacher and Zoom link.
5. Exact dated sessions generated from the course date range and weekly pattern.
6. Individual **Edit session** controls only after a session is selected.

Teacher may be `TBA` in DEVELOPMENT. A scheduled session must have an active teacher before publication.

## Published revisions

Published snapshots are immutable.

- A published course is locked.
- **Revise timetable** reopens the working timetable as DEVELOPMENT while retaining the current publication pointer.
- Changes are not student-current until **Publish revision** creates a new immutable publication.
- `CANCELLED` keeps the original occurrence visible as cancelled in the next publication.
- `RESCHEDULED` keeps the original occurrence and links it to a newly created exact-dated replacement.

## Global Access

The tab is renamed **Global Access**.

The access table uses two header rows:

- row 1: Global Subject names
- row 2: `PAID` or `FREE`

A FREE subject still shows its saved entitlement checkbox/tick. FREE policy grants access implicitly, while the tick records who has a saved paid entitlement if the subject later returns to PAID.

## Timezone

Course Scheduler does not display or edit timezone. New Global Courses inherit central `PlatformTimezone`, currently `Africa/Johannesburg`. Existing run timezone values remain intact for deterministic historical calculations.
