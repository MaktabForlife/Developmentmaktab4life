# V98.14 Apps Script cleanup audit

Date: 2026-08-05

Baseline: merged V98.13 production repository ZIP.

## Result

`apps-script/code.gs` was reduced from 5,716 lines to 1,246 lines. The V98.13
Worker routing remains unchanged: migrated application routes are direct Google
Sheets only, while Weekly Planner preview submission remains Apps Script only.

The cleanup removed every retired migration action from `doPost`, removed the
corresponding legacy implementations and discarded helpers that were reachable
only from those implementations. Duplicate Task Resource helper definitions and
three dead Worker-style handlers embedded in `code.gs` were also removed.

## Retained callable actions and dependency closure

| `doPost` action | Retained dependency closure |
|---|---|
| `registerAdmin` | `generateAdminId`, `generateUniqueId` |
| `getAdminByUsername` | Spreadsheet lookup only |
| `createTaskResource` | Task lookup, Task Resource ID reservation, duplicate-name lookup, text normalization |
| `listTaskResources` | TaskResources sheet read/filter |
| `updateTaskResource` | Task lookup, duplicate-name exclusion lookup, text normalization |
| `populateAllStudentTasks` | Student/Task header mapping, active-value normalization, bulk row assembly, ID reservation |
| `getStudentTaskById` | StudentTasks row loader, StudentRecords lookup, shared header/cell helpers |
| `saveWeeklyPlannerPreviewToDrive` | SystemConfig reader, Drive configuration validation, PNG base64 extraction, filename sanitization |

## Automated guard

`backend/tests/apps-script-cleanup.test.mjs` now:

- parses `code.gs` as JavaScript;
- enforces the exact eight-action `doPost` allowlist;
- confirms retained entry points exist exactly once;
- confirms retired action functions remain absent;
- blocks reintroduction of embedded Worker handlers and legacy labels;
- verifies the bound-spreadsheet and Drive OAuth scopes remain declared.

Run with:

```bash
cd backend
npm run test:apps-script-cleanup
```
