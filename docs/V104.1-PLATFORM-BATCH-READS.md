# V104.1 Platform Batch Reads

V104.1 introduces a validated multi-tab Platform read helper and applies it to the highest-volume Platform startup paths.

## New helper

`readPlatformSheets(env, sheetNames)` lives in `backend/src/lib/platform-sheet.js`.

It uses the existing Google Sheets `values:batchGet` client and returns a keyed object whose values have already passed the same strict Platform header/schema validation used by `readPlatformSheet()`.

## Converted paths

- Academy Home Platform timetable state: 13 individual Platform reads → 1 batchGet.
- Central account state used by account check/login/context construction: 2–8 individual Platform reads → 1 batchGet.
- GLOBAL central-session access validation: 3 Global Platform tab reads → 1 batchGet (credential row remains independently revalidated).

## Not converted in this component

- Reboot/Program spreadsheet timetable reads.
- Course-scoped central session row + registry + membership deduplication.
- Attendance, Progress, Planner and Resource Program read sets.

Those remain functionally unchanged and are candidates for V104.2/V104.3.

## Deployment

There is no Sheet migration. `PlatformConfig!B3` remains `102.0.9` with 19 required Platform tabs.
