# V102.12.1 Platform Sheet migration

V102.12.1 moves Platform schema from `102.0.7` to `102.0.8` and increases the required Platform tabs from 18 to 19.

## Safe deployment order

1. Back up the Platform Sheet.
2. Keep `PlatformConfig!B3` (`PlatformSchemaVersion`) at `102.0.7`.
3. Create a new tab named exactly `AcademyCalendar`.
4. Import `docs/V102.12.1-AcademyCalendar-template.csv` into `AcademyCalendar` starting at `A1`.
5. Confirm the exact header row below and 42 seeded Islamic reference rows.
6. Do not create rows for South African public holidays. They are generated automatically by the Worker.
7. Deploy Pages and Worker from the same V102.12.1 commit.
8. After both are live, change `PlatformConfig!B3` from `102.0.7` to `102.0.8`.
9. Run Platform validation.
10. Open **Admin → Academy Calendar**, confirm public holidays and Islamic dates render, then create the Academy Terms required for the year.

## `AcademyCalendar` exact headers

Place these headers in row 1, columns A:N:

| Column | Header |
| --- | --- |
| A | `CalendarEventID` |
| B | `EventType` |
| C | `Description` |
| D | `StartDate` |
| E | `EndDate` |
| F | `AlternateDate` |
| G | `TeachingImpact` |
| H | `Active` |
| I | `CreatedDate` |
| J | `CreatedByAccountID` |
| K | `CreatedByAccountName` |
| L | `ModifiedByAccountID` |
| M | `ModifiedByAccountName` |
| N | `ModifiedDate` |

## Seed rows

`V102.12.1-AcademyCalendar-template.csv` contains 42 `ISLAMIC_DAY` rows for 2025–2030.

- `StartDate` and `EndDate` initially contain the document's Most Likely Date.
- `AlternateDate` contains the document's Alternate Date.
- `TeachingImpact` is initially `INFORMATION`.
- `Active` is `TRUE`.
- Audit columns may remain blank for these one-time reference seed rows.

Do not alter the supplied Islamic descriptions during import.

## Terms

Do not add term rows manually during migration. After V102.12.1 is live, create terms through **Admin → Academy Calendar** so IDs and audit fields are generated by the Worker.

## Validation target

After the schema marker is changed to `102.0.8`, Platform validation should report:

- Platform schema `102.0.8`
- 19 required tabs
- `AcademyCalendar` present with the exact headers
- 42 initial Islamic reference rows before any Terms are added
- existing Global Curriculum, Global Access and timetable/publication validation still passing

## Rollback

If rollback is required:

1. Change `PlatformConfig!B3` back to `102.0.7` first.
2. Revert Pages and Worker to the deployed V102.12 commit together.
3. Leave the additive `AcademyCalendar` tab in place; V102.12 does not use it.
4. Do not delete or alter Program timetable or Global Course publication data.
