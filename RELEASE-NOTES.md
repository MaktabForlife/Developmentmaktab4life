V102.11.2

Course Scheduler usability refinement over V102.11.1.

- 24-hour Course Scheduler time entry/display uses `13h00` format.
- One schedule line can select multiple weekdays.
- Course setup is compact and keeps subject/name/dates/active state on one row on larger screens.
- Setup/Modify actions moved into the course setup header.
- Session editing is inline in DEVELOPMENT/REVISION.
- CANCELLED and linked RESCHEDULED workflows remain supported.
- Save actions use icon buttons with accessible labels.
- Global Access has a separate Unique ID column.
- Platform schema stays `102.0.7`; no Sheet migration is required.
- No repository paths are deleted.
