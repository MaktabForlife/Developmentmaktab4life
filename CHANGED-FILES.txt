- js/m4l-manage-resources.js
- version.json
- js/version.json

Tests changed
-------------
- backend/tests/resource-management-ui.test.mjs

What changed
------------
- Removed the optional Task selector from Add Resource and Modify Resource.
- Removed the visible Format field from Add Resource and Modify Resource.
- TaskId remains an existing sheet column for compatibility but the Library management UI no longer sends a Task selection.
- Resource format remains automatically derived from the selected Drive file by the Worker and may continue to be stored in the existing format column.
- No Worker deployment is required for this revision.

M4L V100.4.3

Runtime files changed
---------------------
Worker:
- backend/src/routes/drive-library.js

Version metadata:
- version.json
- js/version.json

Tests changed
-------------
- backend/tests/drive-library.test.mjs

What changed
------------
- Library module choices are now read from ModuleList, not inferred from TaskList.
- ModuleID, ModuleName, SubjectID, Active and Sort Order come from ModuleList.
- TaskList is used only to attach active tasks to existing active modules.
- Active ModuleList modules with zero tasks still appear in the Library resource form.
- Inactive ModuleList modules are excluded.
- Legacy tasks with ModuleName but no ModuleID may match an existing ModuleList module by name; TaskList never creates a module.
