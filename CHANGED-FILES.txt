Deployment order
1. Back up the Google Sheet.
2. Confirm Courses, TimeSlots and TimetableSessions use the exact V101.4 templates.
3. Create TimetableCourseState, TimetablePublications and
   PublishedTimetableSessions using the exact V101.4.3 templates.
4. Confirm V101.3 AdminAuditLog and existing curriculum attribution columns.
5. Deploy the Worker/backend.
6. Deploy the frontend and version metadata.
7. Build, validate and publish one course snapshot without changing the existing
   live timetable source.

V101.4 does not publish builder sessions. TeacherAssign and TimeTable remain the
live read source. No Apps Script deployment, Worker binding, or Cloudflare
variable change is required.

V101.4.1 adds no Sheet headers. It adds multi-day/group creation, detailed
in-dialog conflict feedback and 24-hour time display.

V101.4.2 adds repeatable lesson rows and creates every lesson/day/group
combination in one validated session append. It adds no Sheet headers.

V101.4.3 replaces lesson rows with per-group assignments and adds three Sheet
tabs for stage, publication metadata and immutable session snapshots.
