V102.1

No existing repository files, course Sheet tabs or course Library records
should be deleted in this release.

The proposed central `GlobalResources` tab is intentionally not created:
Libraries and resources belong to courses. This is a schema decision, not a
deletion from any existing workbook.

The proposed `PlatformPermissions` tab is also intentionally not created:
authorization is defined directly by ADMIN, SENIOR, TEACHER and STUDENT roles.

Create `Courses`, `TimeSlots`, and `TimetableSessions`. Keep `SystemConfig`,
`AdminAuditLog`, `SubjectList`, `ModuleList`, `TaskList`, `TeacherAssign`, and
`TimeTable`. The last two remain the live timetable source in V101.4.

V101.4.1 introduces no additional tabs and deletes no V101.4 data.

V101.4.2 introduces no additional tabs and deletes no V101.4 data.

V101.4.3 adds three tabs but deletes no existing repository files, Sheet tabs,
or historical timetable data. Published snapshot rows must never be deleted.
