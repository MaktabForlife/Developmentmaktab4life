# V102.12.1 — Academy Calendar

## Purpose

Academy Calendar is a central Platform calendar used by Academy Home and scheduling. It is separate from Program timetable storage and Global Course publication history.

## Calendar sources

### South African public holidays

Public holidays are generated automatically by the Worker for any requested year. Every public-holiday entry is displayed simply as `Public Holiday`.

The generator includes the fixed South African public-holiday dates plus Good Friday and Family Day calculated from Easter. If a public holiday falls on a Sunday, the following Monday is also generated as a `Public Holiday`.

Public holidays have `TeachingImpact = NO_TEACHING`. They are virtual calendar events and are not stored as rows in `AcademyCalendar`.

### Significant Islamic dates

The V102.12.1 migration seeds the Most Likely Date and Alternate Date from `Significant-Days-of-the-Islamic-Year-2025-to-2030-for-South-Africa.pdf`.

Descriptions are retained exactly as the reference document uses them:

- `Laylatul-Bara'ah (Eve)`
- `First Taraweeh`
- `First Fast`
- `Eid-ul-Fitr`
- `Eid-ul-Adha`
- `New Islamic Year`
- `‘Aashuraa`

Islamic reference dates default to `TeachingImpact = INFORMATION`. Admin may adjust the date/alternate date or explicitly change an individual Islamic date to `NO_TEACHING` if Academy policy requires it.

Two informational periods are derived from the stored Islamic dates:

- `Ramadaan`: First Fast through the day before Eid-ul-Fitr.
- `First 10 Days of Zul Hijjah`: nine days before Eid-ul-Adha through Eid-ul-Adha.

The derived periods are not stored as extra Sheet rows.

### Terms

Terms are created and modified by Admin in **Admin → Academy Calendar**. Terms are stored as `TERM` rows and default to `TeachingImpact = INFORMATION`.

## Timetable interaction

Calendar data never rewrites a published timetable.

When Global Course sessions are generated, any generated session on a `NO_TEACHING` date is returned as a warning. The session remains in DEVELOPMENT so Admin can review it and use the normal Cancel/Reschedule workflow where required.

Published Program or Global Course sessions remain immutable. If an Academy closure is added after publication, revise the relevant timetable and publish a new revision rather than changing history in place.

## Academy Home

Academy Home receives calendar context together with the weekly timetable:

- Term and significant religious periods are shown as week context.
- Public holidays and significant Islamic days are shown on the affected date.
- Timetable sessions remain visible even on `NO_TEACHING` dates so the system never silently hides a published conflict.
