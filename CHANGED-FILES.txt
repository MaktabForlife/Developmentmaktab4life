Important boundaries
1. Create a new, separate Platform Sheet from the nine exact templates.
2. Add PLATFORM_SPREADSHEET_ID without removing GOOGLE_SPREADSHEET_ID.
3. Deploy development and run Validate Platform Sheet from ADMIN System Settings.
4. Keep all current V101.4.3 application-data routes on the Reboot Sheet.
5. Keep each course Library and its resources course-specific.
6. Do not activate /account/<uniqueid> until central authentication and
   CourseID/role-scoped tokens are implemented.
7. Keep TeacherAssign and TimeTable as the live timetable source until the
   published read cutover is separately verified.

Rollback
V102.1 adds only the ADMIN validation read. It does not redirect existing
application-data endpoints through CourseRegistry. Reverting the Worker leaves
V101.4.3 data routing unchanged.
