What changed
------------
- Retired the old M4L_BACKEND_* backend-selector mechanism.
- Backend ownership is now fixed in code: Google Sheets for application data, Apps Script only for Weekly Planner PNG-to-Drive, and Worker for Worker-native services.
- Removed the retired M4L_BACKEND_* selector values from both production and development Wrangler vars.
- Stale selector variables left temporarily in the Cloudflare dashboard are ignored by the Worker, making manual dashboard cleanup safe after deployment.
- APPS_SCRIPT_URL remains because the Weekly Planner PNG-to-Drive bridge still calls the bound Apps Script web app.
- M4L_BACKEND_ROUTING_LOGS remains an optional logging toggle and is not a backend selector.
- apps-script/code.gs was audited and requires no change: saveWeeklyPlannerPreviewToDrive remains the only callable doPost action.
- Worker health/package/version metadata updated to V100.5.
- All 23 backend regression test files pass.
- Wrangler dry-run was not run because Wrangler is not installed in this environment.

What changed
------------
- Library module choices are now read from ModuleList, not inferred from TaskList.
- ModuleID, ModuleName, SubjectID, Active and Sort Order come from ModuleList.
- TaskList is used only to attach active tasks to existing active modules.
- Active ModuleList modules with zero tasks still appear in the Library resource form.
- Inactive ModuleList modules are excluded.
- Legacy tasks with ModuleName but no ModuleID may match an existing ModuleList module by name; TaskList never creates a module.
