Deployment order
1. Back up the Google Sheet.
2. Create AdminAuditLog and append the documented audit columns.
3. Deploy the Worker/backend.
4. Deploy version.json and js/version.json.
5. Run the creation, modification and sensitive-data verification checklist.

The Sheet migration must precede the Worker because audited writes fail closed.
No Apps Script deployment, Worker binding or Cloudflare-variable change is
required. Do not delete TimeTable or TeacherAssign.
