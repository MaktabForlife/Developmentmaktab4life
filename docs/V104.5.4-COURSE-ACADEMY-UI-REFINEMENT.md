# V104.5.4 — Course and Academy Timetable UI Refinement

V104.5.4 is a presentation/workflow refinement on top of V104.5.3. It does **not** change the Platform schema (`102.0.12`), Course scheduling architecture, access rules or Google Sheets read architecture.

## Academy Course identity

Global Course timetable pills now use the **published Course Name** as the primary label for both DERIVED and EXPLICIT Courses.

Example:

```text
Course: History of the Quran
Global Subject: Tafseer & Tadabbur

Academy primary label: History of the Quran
Secondary academic detail may still include subject/module/teacher.
```

The label is resolved from immutable publication/session display values first. This means editing the current Course row does not rewrite the name of an already-published timetable version.

The Hifz derived path is regression-protected: a published Mon–Thu Hifz recurrence appears in the Academy day calendar without any normal materialised published-session rows.

## Academy pill presentation

Detailed (large) timetable pills centre their content. A current session with an authorised Zoom link becomes a single active Zoom action:

- the whole pill uses the existing Academy purple Zoom/brand treatment;
- the whole pill remains the clickable link;
- `Zoom` includes the supplied Lucide link icon;
- cancelled sessions remain non-clickable for Zoom.

## Publish control

The Course row remains the only publication location.

For a **saved** Course, Publish no longer disappears when unavailable. It remains visible and disabled for conditions such as:

- already published with no saved revision;
- unsaved edits waiting for the main Course Save;
- inactive Course;
- no valid schedule;
- invalid/missing ONGOING draft publication window.

An unsaved local `+ Add Course` draft still has no Publish control because it does not yet have a persisted RunID.

## Recurring schedule editor

New time slots no longer suggest real default times. Start and End are blank and display `--h--` until the administrator deliberately enters valid times.

The schedule actions are simplified:

- remove the large top-right `+ Another Time Slot` button;
- add a light `+ Add another time slot` action beneath the rows;
- replace row X removal with the supplied Lucide `trash-2` icon;
- rename DERIVED `Exceptions` action to singular `Exception` so it fits inside the action pill.

## Verification

- Platform schema remains `102.0.12`; no migration is required.
- V104.3 request-level read deduplication remains protected.
- V104.4 read audit remains 23 direct-read call sites across 17 files and 15 batch-read call sites.
- V104.5.3 Hifz/ONGOING authoritative draft-window regression remains protected.
