Deployment order
1. Back up the Google Sheet.
2. Create Courses, TimeSlots and TimetableSessions using the exact templates.
3. Confirm V101.3 AdminAuditLog and existing curriculum attribution columns.
4. Deploy the Worker/backend.
5. Deploy the frontend and version metadata.
6. Build and verify one course without changing the existing live timetable.

V101.4 does not publish builder sessions. TeacherAssign and TimeTable remain the
live read source. No Apps Script deployment, Worker binding, or Cloudflare
variable change is required.

V101.4.1 adds no Sheet headers. It adds multi-day/group creation, detailed
in-dialog conflict feedback and 24-hour time display.
