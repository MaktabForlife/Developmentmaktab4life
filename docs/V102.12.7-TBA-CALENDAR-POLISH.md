# V102.12.7 — Publishable TBA + Academic Calendar polish

## Purpose

This patch corrects two review findings after V102.12.6 without changing the Platform schema or starting the V103 Central Identity migration.

## Global Course teacher state

`TBA` is a valid teacher state for both development and publication.

- `TeacherAccountID = ""`
- published `TeacherName = "TBA"`
- no placeholder account is created
- a nonblank TeacherAccountID must still identify an active account
- TBA can later be replaced by a real teacher through the normal revise/edit/publish workflow

## Academic Calendar toolbar

The app foundation sets ordinary buttons to `width:100%`. V102.12.6 did not explicitly override that width on the Today control, so the button could consume the available toolbar width and clip the month/year controls. V102.12.7 gives Today an explicit compact width and keeps Year pushed to the right with a flex-safe layout.

## Mobile Holidays

At phone widths, each Holiday uses one grid row with three columns:

1. flexible description
2. compact date
3. remove (`×`)

The section-level batch-save semantics introduced in V102.12.6 are unchanged.

## Schema

No migration. Keep `PlatformConfig!B3 = 102.0.8` and 19 required Platform tabs.

## Deferred architecture

The agreed V103 unified Academy Access Matrix is not part of this patch. It will become the single UI/source for contextual roles across Reboot, Aalimiyyah, Global Subjects and Global Courses.
