# V102.11 Global Subject timetable

V102.11 adds an exact-dated, central timetable for Global Subjects. It is independent of course Sheets and is tied to finite `GlobalSubjectRuns`.

## Data model

- `GlobalTimetableSessions` — editable DEVELOPMENT source sessions using exact `YYYY-MM-DD` dates.
- `GlobalTimetableRunState` — one state row per scheduled run: `DEVELOPMENT` or `PUBLISHED`.
- `GlobalTimetablePublications` — immutable publication headers with per-run version numbers.
- `PublishedGlobalTimetableSessions` — immutable session snapshots for each publication.
- `PlatformConfig.GlobalTimetableVersion` — publication-level cache/integration version. It increments only after a successful publish.

Teacher assignment uses central `UserAccounts.AccountID`; a course membership is not required. The admin must select a teacher explicitly. Optional Zoom overrides must use HTTPS.

## Development workflow

Choose an active Global Subject run in **Global Curriculum → Schedule**, choose one or more weekdays, start/end time, teacher, optional module and optional Zoom link, then generate. V102.11 creates the exact dates that occur between the run start/end dates inclusive.

Each generated date can then be edited individually or deactivated for holidays and gaps. A run's Delivery dates cannot be shortened so that an existing timetable session falls outside the new boundaries.

Any source-session change places the run timetable in `DEVELOPMENT`. If the run was already published, `CurrentPublicationID` is preserved so the previous published snapshot remains intact until a new publication is created.

## Publication

Publish snapshots **active** source sessions only. Each publication:

1. appends a `GTPUB-<UUID>` row with the next per-run `VersionNo`;
2. appends immutable `GTPSESSION-<UUID>` rows;
3. snapshots RunName, SubjectName, ModuleName, TeacherName and Timezone;
4. moves the run state to `PUBLISHED` and points `CurrentPublicationID` at the new publication;
5. increments `GlobalTimetableVersion` exactly once;
6. writes a Platform audit row.

Old publication and snapshot rows are never edited by the V102.11 runtime.

## Access model

V102.11 does not change the V102.10 Global Subject access model. `FREE` remains implicit for active central accounts; `SUBSCRIPTION` remains controlled by `GlobalSubjectAccessMatrix`. Global timetable publication does not revoke or grant resource entitlement.

## Scope boundary

V102.11 builds the central schedule and immutable publication foundation only. Academy timetable aggregation and Student/Teacher presentation are V102.12 work. Billing, subscription expiry, cross-course conflicts and Aalimiyah onboarding remain out of scope.
