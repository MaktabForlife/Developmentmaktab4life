# V103.1.0.1 Global Curriculum Inline Editor

## Purpose

This patch corrects a pre-existing UI responsibility split: Global Subject and Module definition belongs in the Subjects workspace, while Course Scheduler should schedule delivery only.

It is intentionally independent of the V103 Central Identity migration.

## UI model

Each Subject row contains:

- Subject name + SubjectID reference;
- access policy (`FREE` / `PAID`);
- status (`ACTIVE` / `INACTIVE`);
- Modules dropdown with Module count.

Expanding Modules shows rows containing:

- order;
- Module name + ModuleID reference;
- status.

The standalone Modules tab is removed.

## Draft state

Subject/Module edits are held in browser draft state. The editor compares each draft to the server-loaded original and highlights changed rows. New Subjects/Modules are also dirty by definition.

One Save action persists the changed set.

## API

`POST /api/admin/platform/global/subjects/save-batch`

Payload contains:

- `globalCurriculumVersion`;
- changed Subjects;
- changed Modules;
- client keys so a newly added Module can reference a newly added Subject before the Worker assigns permanent IDs.

The Worker:

1. resolves ADMIN/GLOBAL_ADMIN authority;
2. reads the current Platform curriculum tables;
3. rejects a stale curriculum version;
4. validates the complete Subject set;
5. allocates permanent IDs for new Subjects;
6. validates/creates access policies and Access Matrix columns;
7. validates the complete Module set, including Modules under newly-created Subjects;
8. performs no write when validation fails;
9. on success, writes all changed curriculum rows, the single curriculum-version increment and audit entries in one Google Sheets `values:batchUpdate` call.

## Existing APIs

The older individual Subject/Module save endpoints remain available for backward compatibility but are no longer used by the Subjects screen.

## Course Scheduler

Course Scheduler no longer renders or saves the Subject management table. It continues to read Global Subjects/Modules through its existing delivery/timetable endpoints and uses them in course/session selectors.

## Data/schema impact

No new Sheet/table/column is introduced. PlatformSchemaVersion remains `102.0.8` with 19 required tabs.

The V103.1 Identity Links migration remains a separate controlled Reboot operational migration.
