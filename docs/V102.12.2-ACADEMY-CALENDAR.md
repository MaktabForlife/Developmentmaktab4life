# V102.12.2 — Academy Calendar inline refinement

V102.12.2 keeps the V102.12.1 `AcademyCalendar` Platform tab and `PlatformSchemaVersion = 102.0.8`. No new tab or header is required.

## Page layout

The Admin Academy Calendar is arranged as:

1. **Calendar** — full width.
2. **Terms** — full width.
3. **Islamic Dates** — 50% width on larger screens.
4. **Public Holidays** — 50% width on larger screens.

Islamic Dates and Public Holidays stack vertically on smaller screens.

## Inline editing

There is no separate Calendar edit panel.

- Terms are edited directly in their row and saved with the save icon.
- Islamic dates are edited directly in their row and saved with the save icon.
- Public Holiday dates are edited directly in their row and saved with the save icon.
- `×` removes a Public Holiday from the effective Academy Calendar.
- `+` after the Public Holiday list adds another Public Holiday.

## South African Public Holidays

The standard South African dates continue to be generated by the Worker, including Good Friday, Family Day and the rule that a Public Holiday falling on Sunday makes the following Monday a Public Holiday too.

All are displayed simply as `Public Holiday`.

V102.12.2 makes generated holidays editable without materialising all standard holidays into the Sheet. The UI writes only exceptions to `AcademyCalendar`:

- deleting a generated day records an inactive `PUBLIC_HOLIDAY` override for that date;
- moving a generated day records an inactive override for the original date plus an active override for the replacement date;
- adding a day records an active `PUBLIC_HOLIDAY` override.

Public Holiday overrides always use `Description = Public Holiday` and `TeachingImpact = NO_TEACHING`.

## Islamic dates

`First Fast` is no longer displayed or used as a calendar event. Existing V102.12.1 `First Fast` rows may remain in the Sheet as dormant legacy reference rows; V102.12.2 ignores them.

Ramadaan is derived from the day after **First Taraweeh** through the day before Eid-ul-Fitr.

Each Islamic event displays the description first and the Islamic date directly underneath, for example:

- `Laylatul-Bara'ah (Eve)` / `15 Sha'baan 1447`
- `First Taraweeh` / `1 Ramadaan 1447`
- `Eid-ul-Fitr` / `1 Shawwal 1447`
- `Eid-ul-Adha` / `10 Zul Hijjah 1447`
- `New Islamic Year` / `1 Muharram 1448`
- `‘Aashuraa` / `10 Muharram 1448`

The Gregorian Most Likely and Alternate dates remain editable inline. The Islamic description remains fixed to the supplied South African reference document.

For a fresh Academy Calendar setup, `V102.12.2-AcademyCalendar-template.csv` contains 36 visible Islamic reference rows for 2025–2030 and omits the six `First Fast` rows.

## Timetable behavior

Calendar `NO_TEACHING` warnings continue to flow to Course Scheduler. Published timetable history is never rewritten automatically. Academy Home also receives the updated effective calendar and displays the Islamic date beneath the Islamic event description.
