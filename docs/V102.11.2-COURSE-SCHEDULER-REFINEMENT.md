# V102.11.2 — Course Scheduler refinement

This release changes presentation and interaction only. Platform schema remains `102.0.7`.

## Weekly time-period row

A single UI row can represent several weekdays that share the same time and teaching details, for example:

`Mon Tue Wed Thu | 04h00 | 05h00 | Module | Teacher | Zoom link`

The browser submits the selected weekday array to the existing exact-date generator. Storage remains exact dated sessions with canonical `HH:MM` values; `13h00` is the UI format.

## Inline session editing

In DEVELOPMENT/REVISION, each exact dated session can be edited directly in its row. Published snapshots remain immutable. `CANCELLED` changes lifecycle state; `RESCHEDULED` creates a linked replacement through the existing lifecycle API.

## Global Access

`UserAccounts.UniqueID` is shown in a dedicated column. `AccountID` remains the internal key and is not exposed as the user-facing identifier.

## Sheet impact

None. No migration or template is required.
