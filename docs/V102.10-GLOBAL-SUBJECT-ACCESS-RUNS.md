# V102.10 global-subject access matrix, policy and scheduled-run foundation

V102.10 separates four concerns:

- **Subject status** — `GlobalSubjectList.Active`.
- **Access model** — `FREE` or `SUBSCRIPTION` in `GlobalSubjectAccessPolicy`.
- **Current subscription entitlement** — TRUE/FALSE in `GlobalSubjectAccessMatrix`.
- **Teaching run status** — derived from `GlobalSubjectRuns` dates, timezone and `Active`.

An active subject may remain accessible when it has no current teaching run. Ending a run never deactivates the subject or removes recordings/handouts.

## Access matrix

`GlobalSubjectAccessMatrix` has one row per central account and one column per global SubjectID. Column A is always `AccountID`. Subject names are display data joined by the UI and are never matrix keys.

- `FREE`: access is implicit for every active central account; matrix values are ignored while FREE.
- `SUBSCRIPTION`: the account must have TRUE in that subject's matrix column.
- Changing SUBSCRIPTION → FREE preserves the matrix values.
- Changing FREE → SUBSCRIPTION makes the preserved values effective again.
- The old `UserGlobalSubjectAccess` rows are retained unchanged as legacy migration/rollback history, not live V102.10 authorization.

New global subjects receive an active SUBSCRIPTION policy plus a new matrix column defaulted FALSE for all existing accounts. Newly migrated central accounts receive a matrix row defaulted FALSE across existing subject columns.

## Access policy

Every global subject must have exactly one active `GlobalSubjectAccessPolicy` row. Missing, inactive, duplicated or invalid policy data never widens access: runtime falls closed to SUBSCRIPTION and Platform validation reports the data problem. Existing global subjects migrate as SUBSCRIPTION.

Policy IDs use `GSPOL-<UUID>`. FREE access never creates per-user rows.

## Scheduled runs

`GlobalSubjectRuns` stores finite, repeatable teaching periods. Run status is derived, never manually stored. For an active row in its own IANA timezone:

- before StartDate → `UPCOMING`;
- StartDate through EndDate inclusive → `CURRENT`;
- after EndDate → `ENDED`;
- inactive row → `INACTIVE`.

Library delivery state is `CURRENT`, else `UPCOMING`, else `PAST`, else `NOT SCHEDULED`. Run dates are `YYYY-MM-DD`; EndDate cannot precede StartDate.

## Admin UI

Global Curriculum contains:

- **Access Matrix** — current per-account SUBSCRIPTION flags; FREE cells display FREE rather than an editable entitlement checkbox.
- **Delivery** — subject policy plus finite run creation/edit/activation and derived status.

Matrix access changes write `PlatformAuditLog` but do not change `GlobalCurriculumVersion`. Policy/run changes write audit rows and update `GlobalCurriculumVersion`.

## Backend enforcement

The same policy + matrix decision is used by the unified global Library, global-only account context/session validation and protected Global Resources Drive authorization. Ending a run never revokes a resource when policy entitlement is still valid.

## Not included

V102.10 does not create/publish global timetable sessions, aggregate the academy timetable, onboard Aalimiyah, add billing/payment/expiry, or implement cross-course conflict rules.
